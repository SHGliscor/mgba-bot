Pokebot3DS-CFW — Gen 3 Starter Hunter v0p21 HF1

UI BASE
This build uses the v0p19 Current UI / Pokémon-themed dashboard. It is not the
older compact UI that accidentally returned in v0p20/v0p21.

SUPPORTED
Ruby AXVE v1.0/v1.1 and Sapphire AXPE v1.0/v1.1.

RUN
1. Install/launch the included v0p21 mGBA CIA.
2. Load the save at Birch's bag on Route 101 with an empty party.
3. Run requirements.bat once if needed.
4. Run run_UI.bat.

The UI auto-detects Ruby/Sapphire and revision 00/01.
